# iOS Launch — App Store submission assets

This folder holds everything used to submit and list **MathFlux** on the Apple
App Store. MathFlux is **live**: https://apps.apple.com/us/app/mathflux/id6762221667

## Contents

| Path | What it is |
|------|------------|
| `app-store-listing.md` | App Store listing copy — name, descriptions, keywords, IAP catalog, content declarations |
| `content-rating.md` | Age-rating questionnaire answers (Ages 5+) |
| `data-safety.md` | Privacy / data-collection disclosures |
| `feature-graphic.png` / `.svg` | Promotional feature graphic |
| `screenshots/` | Curated store screenshots (`shot-*.png`) |
| `achievements/` | Game Center achievement icons |

## Notes

- The listing copy still includes a cross-platform note; Android is planned for a
  future release and is not yet live.
- IAP product IDs use the legacy `Samuel.Praxis_Math.*` convention — frozen, do
  not rename (see `app-store-listing.md`).
